# Website audit & optimization — October 2026

Scope: page architecture, Canadian/Alberta compliance (tax/accounting, insurance, mortgage, investment, privacy, advertising) and local SEO for Sherwood Park / Edmonton.
This is a practical web review, not legal advice — have the client's compliance contact or lawyer confirm the items marked **CLIENT**.

## 1. What was broken (fixed)

| Issue | Impact | Fix |
|---|---|---|
| Insurance-page form inputs had no `name` attributes; investment & calculator forms called a function that didn't exist; accounting/other-services form scripts had syntax errors | Most service-page inquiries were never delivered (or arrived empty) | One shared form handler (`assets/js/site.js`) and one form markup on every page; tested end-to-end |
| Insurance-page calculator had no script | "Calculate" did nothing | Shared `assets/js/calculators.js` |
| Life-insurance calculator multiplied **annual** income × years × 12 | Coverage need overstated 12× | Fixed on all three calculators |
| Mortgage calculators used US-style monthly compounding | Payments wrong for Canadian fixed-rate mortgages | Semi-annual compounding (Interest Act convention); label "Loan Term" → "Amortization" |
| Cloudflare email-obfuscation code copied from another host | Emails displayed as "[email protected]" on GitHub Pages; one page pointed to `broadmoorfinancials.ca` | Plain `mailto:` links everywhere |
| Header/footer injected by JavaScript (`navbar.js`/`footer.js`), plus leftover duplicate nav markup in each page | Nav/footer links invisible to crawlers without JS; stray white gap and ghost menu | Header/footer now inlined at build time from `partials/` |
| Homepage was 1.5 MB (26 base64 images, incl. duplicates) | Slow LCP, poor Core Web Vitals | Images extracted to WebP files — homepage HTML now ~150 KB, all images ~270 KB |
| Duplicate script blocks on the homepage | JS errors ("Identifier already declared") | Removed |
| Footer links "About / Testimonials / Partners / Privacy / Terms / Disclaimer" all pointed to `#` | Dead links; no privacy policy despite collecting personal info | Real legal pages added; dead links removed |
| Contact-page Google Map used a fabricated embed URL; FAQ toggle function missing | Map could show wrong place; FAQ didn't open | Address-based embed; `toggleFaq` added |

## 3. SEO (Edmonton / Sherwood Park)

- Unique `<title>` + meta description per page targeting Sherwood Park / Edmonton intent (managed in `tools/pages.json`).
- Canonical URLs, Open Graph/Twitter cards (1200×630 image), `en-CA` language, geo meta, favicon/touch icon.
- JSON-LD: `AccountingService` (NAP, hours, areaServed: Edmonton, Sherwood Park, Strathcona County, St. Albert, Fort Saskatchewan, Spruce Grove, Leduc, Beaumont), `WebSite`, `WebPage` + `BreadcrumbList`, `Service`, and `FAQPage` generated from on-page FAQs.
- New **Serving Edmonton & Area** page (`edmonton-accountant.html`): Edmonton-specific services, Alberta AT1 / no-PST / GST content, tax-deadline table, communities served, FAQs. Honest service-area framing — no fake Edmonton address (avoids Google Business Profile violations).
- Keyword-bearing H1s with location sub-lines; homepage had two H1s → one.
- `sitemap.xml` (auto-generated) and `robots.txt`; custom `404.html`.
- Accessibility: skip link, `aria-current`, alt text, form labels/autocomplete, width/height on hero image.
